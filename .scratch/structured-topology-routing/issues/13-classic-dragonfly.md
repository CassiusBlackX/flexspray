# 识别经典 Dragonfly

自动发现等大小路由器组，验证组内 clique、每组对唯一全局相邻路由器、均匀全局度数和
均匀终端唯一归属，输出组、路由器局部编号、全局链路端点及物理端口映射。

验收：覆盖至少两个不同 `(a, h, p)` 参数组合、打乱节点 ID 和边顺序、并行终端链路，以及
组内缺边、组间缺边、重复组间链路、全局度数不均和终端多归属反例。只承诺默认 metric 的
最短路；UGAL、Valiant、Dragonfly+ 和随机全局布线明确不误认。

完成情况：识别器从具有终端连接的路由器中提出等大小 clique 分区，并验证平衡参数公式、
每组对唯一全局相邻路由器、均匀全局度数和终端归属。已覆盖 `(4, 1, 1)`、`(3, 2, 2)`、
节点和边重排、并行终端/全局链路，以及保持节点度数不变的错误全局重接反例。额外交换机
边只作为未覆盖边保留，不会使已验证 Dragonfly 整体失效。
